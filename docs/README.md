# Documentation

This directory contains the technical documentation for the Qwen Cybersecurity AI Deployment project.

## Documents

### Deployment Guide

Contains the step-by-step process used to deploy the cybersecurity-focused Qwen model with llama.cpp and CUDA.

Topics include:

- Environment preparation
- NVIDIA GPU verification
- CUDA configuration
- llama.cpp compilation
- Model download
- Model integrity verification
- GPU-accelerated inference
- Multi-GPU configuration

### Architecture

Documents the deployment architecture, including:

- Kaggle Linux environment
- CUDA
- llama.cpp
- Dual NVIDIA Tesla T4 GPUs
- Qwen 27B GGUF model
- Cybersecurity inference workflow

### Testing Results

Documents the cybersecurity-focused inference tests and observed results.

Testing areas include:

- SIEM analysis
- EDR analysis
- SOC analyst scenarios
- Inference performance
- Deployment observations

---

## Purpose

The documentation is maintained separately from the main README so that the repository remains organized and the deployment process can be reproduced more easily.
